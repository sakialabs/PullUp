# PullUp changelog

Short, decision-useful milestones only. PullUp remains **pre-T0**; completed technical proofs do not satisfy partner, resident, legal, privacy, accessibility, security, or funding gates.

## Current status

- **Now:** one validated synthetic Place spans Flow, The Rundown, the public API, and local persistence.
- **Data:** fictional Canadian review data only; no applications, payments, bookings, or resident records.
- **Next:** return to the roadmap's Phase 0 partnership, resident, governance, and policy work.
